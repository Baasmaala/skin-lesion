# Synthetic Data Augmentation for Skin Lesion Classification

Deep learning project investigating whether synthetic images generated by a conditional VAE and a conditional GAN can improve a CNN classifier on the heavily imbalanced ISIC 2018 Task 3 skin lesion dataset.

## TL;DR — what we found

| Run                         | Overall macro-F1 | Notes |
|-----------------------------|------------------|-------|
| Baseline, frozen backbone   | 0.550            | ResNet50 head-only training |
| Augmented, frozen backbone  | 0.603            | +CVAE synthetic minorities — within seed noise |
| **Baseline, unfrozen backbone** | **0.738 ± 0.04** | Full fine-tuning, two-LR Adam |
| Augmented, unfrozen backbone | 0.681           | Synthetic data *hurts* once the backbone is unfrozen |

**Headline result.** Unfreezing the ResNet50 backbone with a two-LR optimiser (backbone `1e-5`, head `1e-4`) was by far the biggest single lever — +0.188 macro-F1 over the frozen baseline. The synthetic-augmentation gain on the frozen backbone (+0.053) is inside the seed-noise band (±0.10 between two seeds), so we cannot honestly claim it works. The unfrozen-backbone gain comfortably clears its own noise floor (±0.04).

**Why augmentation backfired with the unfrozen backbone.** Our reading is that the synthetic samples were compensating for a weak (frozen) feature extractor. Once the backbone can learn dermoscopy features itself, the synthetic distribution drifts away from the real one and acts as noise rather than signal.

## Dataset

ISIC 2018 Task 3 — Lesion Diagnosis. 10,015 dermoscopy images, 7 classes, heavily imbalanced (NV ~67%, DF ~1.1%).

Stratified 70/15/15 split into train (7,009), val (1,503), test (1,503). The split is fixed by seed=42 and committed to `data/processed/splits.csv` so every experiment uses the same partition. Raw images and labels are not in git (~3 GB) — see Setup below for how to obtain them.

## Notebooks

The pipeline runs in numerical order. Each notebook saves its outputs to `results/` so later notebooks can read them.

| # | Notebook | What it does |
|---|---|---|
| 01 | `01_eda.ipynb` | Class distribution, sample images, image dimensions |
| 02 | `02_split.ipynb` | Stratified 70/15/15 split → `data/processed/splits.csv` |
| 03 | `03_dataset_sanity.ipynb` | Verify the Dataset class loads images and labels correctly |
| 04 | `04_train_baseline.ipynb` | Baseline ResNet50 classifier, backbone frozen |
| 05 | `05_train_vae.ipynb` | Train conditional VAE on minority classes |
| 06 | `06_train_gan.ipynb` | Train conditional DCGAN on minority classes |
| 07 | `07_generate_synthetic.ipynb` | Sample synthetic images from both generators |
| 08 | `08_eval_fid.ipynb` | FID score per class for CVAE and CGAN |
| 09 | `09_train_augmented.ipynb` | Re-train classifier with real + CVAE synthetic data |
| 10 | `10_analysis.ipynb` | Baseline vs augmented — per-class recall, confusion-matrix delta |
| 11 | `11_final_plots.ipynb` | Report-ready plots |
| 12 | `12_train_unfrozen_ablation.ipynb` | Re-run baseline + augmented with backbone unfrozen |
| 13 | `13_train_augmented_no_akiec.ipynb` | Augmentation ablation: drop AKIEC from synthetic mix |
| 14 | `14_train_augmented_seed_check.ipynb` | Seed-variance check on frozen augmented run |
| 15 | `15_seed_check_unfrozen_baseline.ipynb` | Seed-variance check on the headline unfrozen baseline |

### Data

Download ISIC 2018 Task 3 Training data from <https://challenge.isic-archive.com/data/#2018> and place it under `data/raw/` so the layout is:

```
data/raw/
├── ISIC2018_Task3_Training_Input/      ← 10,015 .jpg files
└── ISIC2018_Task3_Training_GroundTruth.csv
```

Then run `notebooks/02_split.ipynb` once to produce `data/processed/splits.csv`.

### Hardware

Frozen-backbone training runs on CPU in a few minutes per notebook. Full fine-tuning (notebooks 12 and 15) needs a GPU — about 1.5 minutes per epoch on a single CUDA device versus hours on CPU.

## Conventions

- **Seed:** 42 everywhere unless a notebook explicitly varies it for a seed-variance check (notebooks 14 and 15 use 123)
- **Primary metric:** macro-F1, not raw accuracy (a trivial "always NV" predictor scores ~67% accuracy but ~0.12 macro-F1 on this dataset)
- **Loss:** class-weighted CrossEntropyLoss with weights computed from real-train counts; the same weights are used in every training notebook so the loss landscape is comparable across runs
- **Image preprocessing:** Resize to 224×224, ImageNet mean/std normalization
- **Class index mapping** (fixed; do not change):
```python
  CLASS_NAMES = ['MEL', 'NV', 'BCC', 'AKIEC', 'BKL', 'DF', 'VASC']
```

# Skin Lesion Classification with Generative Data Augmentation

A deep learning project investigating whether synthetic images generated by VAEs and GANs can improve classification of minority-class skin lesions (specifically melanoma) on the ISIC 2019 dataset.

## Project Structure

- `data/` — raw and processed ISIC dataset (not in git)
- `src/` — all Python source code
- `configs/` — YAML config files for each experiment
- `notebooks/` — Jupyter notebooks for exploration and analysis
- `results/` — output figures, tables, and metrics
- `models/` — trained model checkpoints (not in git)

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
